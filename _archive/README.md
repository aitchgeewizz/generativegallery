# Archive — historical context only

This folder preserves earlier versions of this project's context. **None of these files are the current spec.** The active spec lives at [`../SPEC.md`](../SPEC.md).

## What's in here

- **`original-portfolio-spec.md`** — The original product spec from when this project was conceived as a personal portfolio site (Cash App / Make Tangible aesthetic, infinite canvas of 3D icons of Hannah's own work). The portfolio direction was set aside; the same canvas mechanic was repurposed for the museum browser that became Slower. Stranger.
- **`portfolio-visual-references/`** — Screenshots of design inspiration (Cash App, Make Tangible) collected during the original portfolio phase.
- **`thesis-source.md`** — The conversation that produced the current thesis in `../SPEC.md`. Useful as a record of *how* the thesis got written and Hannah's iterations on it.

## Why keep this

Two reasons. One, the portfolio idea isn't necessarily dead — it could come back as a sibling project or be re-folded in later. Two, the iteration of the thesis is part of the work; preserving it means future Hannah (or anyone she shares this with) can see the moves and the pushbacks that produced the final voice.
